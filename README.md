# Evershop Complaint Dashboard

Interactive complaint-trends dashboard for USA General Stores (Clarendale & Lark & Clover), pulled from the Complaint Tracker's own data feed.

Password-protected. Static single-page site, deployed via GitHub Pages.

## Pages

- `/` -- Complaint Trends
- `/Evershop-Complaints/` -- Complaints detail
- `/Evershop-OrderEscalations/` -- Order Escalations Dashboard
- `/Evershop-CJ/` -- CJ Order Tracker (order-level status breakdown: unfulfilled, unactioned by CJ, shipped, replaced, out of stock, replacement shipped, refund, in trash)
