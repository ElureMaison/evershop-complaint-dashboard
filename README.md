# yourbadassvaronceph.com

The root of this repo serves **Rona Shella Cacao's profile site** (virtual assistant
portfolio). The Evershop internal dashboards live in subfolders alongside it, each
password-gated and excluded from search engines.

## Pages

- `/` -- Profile site (public, indexable)
- `/Evershop-Complaints/` -- Complaint Trends dashboard (previously served at `/`)
- `/Evershop-OrderEscalations/` -- Order Escalations dashboard
- `/Evershop-CJ/` -- CJ Order Tracker
- `/Evershop-WIIO/` -- WIIO Order Tracker
- `/Evershop-Unfulfilled/` -- Unfulfilled Orders
- `/Evershop-RaisedBySumai/` -- Raised By Sumai queue
- `/Evershop-QAReview/` -- QA Review portal
- `/Evershop-AgentDashboard/` -- Agent dashboard
- `/OKOT-Update/` -- OKOT weekly digest

Static site, deployed via GitHub Pages.
