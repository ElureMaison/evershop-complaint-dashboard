    About this demo. A rebuild of a real QC dashboard with the data swapped for an invented company. The data comes from generate_sample_data.py in this folder (fixed seed, so it reproduces exactly). The page is one HTML file with hand-drawn SVG charts and no libraries. Every panel follows the filters, and every bar, row, card and tile is clickable.
    Definitions. Needed edits = fixed or pulled, of finished products with a QC record. Report fail = fail ÷ (pass + warn + fail). ✗ rate = mismatches ÷ (ok + mismatch) per check. Refund growth compares each product's month 1 with its months 2–3, for products 90+ days past QC.
